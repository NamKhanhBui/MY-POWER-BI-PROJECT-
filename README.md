# Retail Sales & Profitability Analytics Dashboard

## 📊 Giới thiệu dự án
Hệ thống BI phân tích hiệu suất kinh doanh và lợi nhuận bán lẻ, giúp ban lãnh đạo theo dõi doanh thu cốt lõi, biên lợi nhuận và cảnh báo rủi ro sản phẩm.

## 🛠️ Công nghệ & Công cụ
- **Power BI**, **DAX** (Star Schema, Time Intelligence, Context Transition, SWITCH, ...)
- **Star Schema Modeling** (Fact_Sales, Dim_Products, Dim_Customers, Dim_Calendar, Dim_Slicer_Metric, Dim_Slicer_Target)

## 📌 Các tính năng chính
- Theo dõi các KPI như: Gross Revenue, Core Revenue, Gross Profit, Profit Margin,...
- Tích hợp bộ lọc đa chiều theo thời gian, danh mục sản phẩm và khách hàng.
- Hệ thống định dạng có điều kiện (Conditional Formatting) tự động cảnh báo sản phẩm có biên lợi nhuận thấp (<45%).
